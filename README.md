# Make the Judge Smile

One line (165 characters) about a small good thing that happened today.

> The neighbor left a mango on my doorstep with a note that just said 'too many' — I ate it standing in the hallway, juice on my chin, grinning like I'd won something.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that
variable is set). The program validates the text first: 1–200 characters, a
single line, not only whitespace.
